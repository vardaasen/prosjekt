# IntelliJ IDEA-oppsett

IntelliJ IDEA er primær IDE for prosjektet.

1. Åpne rotmappen `prosjekt`.
2. Velg Java SDK 24.
3. Importer `pom.xml` som Maven-prosjekt.
4. Bruk IntelliJ sin JUnit-runner for tester.
5. Kjør appen med Maven-målet `spring-boot:run` eller `ProsjektApplication`.

Ikke commit bruker-spesifikke `.idea/`-filer. Delbare prosjektfiler kan vurderes senere hvis de gir tydelig verdi.
